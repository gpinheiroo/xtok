# Xtok

Sistema full-stack para gestão de estoque, controle de movimentações e registro de vendas.

## Tecnologias

- **Backend:** Node.js, Express
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)

## Visão Geral

O Xtok é uma aplicação focada no controle centralizado de inventário e vendas. O projeto adota uma arquitetura simplificada, separando a API REST responsável pelas regras de negócio da interface do usuário.

### Funcionalidades Planejadas
- Cadastro e controle de saldo de produtos
- Registro de entradas e saídas de estoque
- Histórico de vendas e resumo de movimentações
